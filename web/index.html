三步开始使用

  1. 连接模型

    右上角填写服务地址、API Key 和模型名称。也可以先用离线示例体验。

  2. 描述需求

    输入要实现的功能，准备任务后确认函数名与验收用例。

  3. 开始审查

    自动编码、验收、审查和修复，完成后复制代码或下载结果。

目前支持 Python 单文件同步函数。验收会在本机运行生成的代码，建议用于自己的课程样例。
