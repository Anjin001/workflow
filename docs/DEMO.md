# 一分钟演示步骤

## 录制前准备

先安装依赖，确认以下命令可运行。若展示真实模型，填写 .env 并提前完成一次真实运行，避免在视频中展示密钥。离线演示要明确说明使用的是固定模型结果。

## 建议脚本

1. 0—10 秒：说明三个 Agent 的职责和共享状态，展示 Design.md 中的流程图。
2. 10—30 秒：运行 `python main.py --mock`，说明初版未处理空列表，实际验收失败，经过修复后重新验证通过。
3. 30—45 秒：打开本次输出的 initial.py、final.py 和 report.md，展示代码变化、版本及审查证据。
4. 45—60 秒：展示 `--mock --scenario stuck` 的已有运行报告，说明修复次数上限与 needs_changes 状态；如已完成真实调用，可展示真实报告中的模型名和结果。

视频不应把固定离线行为描述为真实模型推理。真实模式运行可能超过一分钟，可使用自己真实运行后的报告说明结果。

## 提交前自查

- 新环境能按 README 安装并运行。
- 自动化测试和 Ruff 检查通过。
- 已验证真实模式，或明确说明尚未联调的原因。
- 源码与压缩包无 .env、API Key 和虚拟环境。
- 压缩包改为自己的学号姓名，小于 200 MB。
