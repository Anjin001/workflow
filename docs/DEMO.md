# 一分钟演示步骤

## 录制前准备

双击 start.bat，确认浏览器工作台可用。若展示真实模型，在设置中填写连接并提前完成一次真实运行，避免在视频中显示密钥。离线演示要明确说明使用的是固定模型结果。

## 建议脚本

1. 0—10 秒：展示网页与模型设置，说明编码、审查、修复三个角色。
2. 10—30 秒：点击“无需 Key，体验完整流程”，说明初版空列表验收失败，修复后重新验证通过。
3. 30—45 秒：切换审查意见与验收标签，点击对比初版，展示问题证据和 v1/v2 差异。
4. 45—60 秒：从历史任务打开一份未通过记录，说明修复上限；或展示自己真实调用的报告，然后点击下载结果。

视频不应把固定离线行为描述为真实模型推理。真实模式运行可能超过一分钟，可使用自己真实运行后的报告说明结果。

## 提交前自查

- 新环境能按 README 安装并运行。
- 自动化测试和 Ruff 检查通过。
- 已验证真实模式，或明确说明尚未联调的原因。
- 源码与压缩包无 .env、API Key 和虚拟环境。
- 压缩包改为自己的学号姓名，小于 200 MB。
