# 快速演示

1. 双击 start.bat，打开网页。可以配置真实模型，也可以选择无需密钥的离线体验。
2. 进入「工作流设计」，选择模板、添加分析角色，调整职责与读取信息，连线后检查结构并保存。
3. 返回任务，选择平均值示例，确认固定验收并开始运行。
4. 查看初版空列表验收失败，以及修复后重新验收通过的过程。
5. 切换「流程图」查看各节点执行轮次和输出；启用验证者时，在「问题验证」查看逐条结论。
6. 对比初版与修复版源码，下载报告或结果包，也可以重新打开历史任务。

离线角色返回固定演示结果，验收会真实执行；不要将其视为真实模型提示词效果。展示真实模型设置时避免暴露 API Key。
