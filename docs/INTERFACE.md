# 网页使用与交互设计

## 入口

双击项目根目录的 start.bat。首次启动会准备 Python 虚拟环境并安装依赖，需要网络和 Python 3.11+；之后自动进入浏览器，不再要求编辑 .env 或输入命令。

重复双击时复用已有服务；默认地址为 http://127.0.0.1:8765，端口占用时自动选择后续可用端口。关闭启动窗口会停止服务，关掉网页不会终止后台任务。

## 使用流程

1. 在模型设置中选择服务，填写 API Key、模型地址、模型名。支持基础地址或完整 /chat/completions 地址，也可读取模型列表。
2. 输入自然语言需求，点击“准备任务”。编码角色先整理函数入口与建议验收用例，暂不执行代码。
3. 核对或编辑预期结果，确认验收后点击“开始审查”。确认后的用例在本轮运行中固定，修复角色只能改代码。
4. 查看编码、验收、审查和修复的阶段进度；结果区可查看代码版本、前后对比、问题证据、验收结果与过程。
5. 复制代码或下载结果包，历史任务可从左侧重新打开。

内置示例可直接载入，不需要准备请求。“无需 Key，体验完整流程”会明确切换离线模型并运行平均值示例。固定离线行为不等于真实模型推理。

## 设置与记录

服务地址、模型名和运行模式可以在浏览器中记住；API Key 只在当前页面内存中保留，刷新网页后需重新填写。后台仅为当前请求或任务持有密钥，不将它写入日志、报告、.env 或提交包。

读取模型列表只验证连接，不代表所选模型、JSON 模式或真实编码效果已经验证。其他兼容接口不支持 response_format 时，可以在兼容设置中关闭 JSON 模式。

同一时刻运行一个工作流。停止是协作式取消：当前请求或验收步骤完成后生效，不强行终止线程。未完成的记录在服务重启后标为中断，不会伪装成成功。

本地服务只绑定回环地址，校验 Host、同源请求和页面随机令牌，无公网托管。网页支持的任务范围仍是 Python 单文件同步函数；代码会在本机执行，不构成安全沙箱。

## 开源交互参考

- [Open WebUI](https://github.com/open-webui/open-webui)：参考集中配置模型服务、以工作区承载交互的产品方向。
- [LobeHub](https://github.com/lobehub/lobehub)：参考任务/会话导航与主工作区的分离方式。
- [Dify](https://github.com/langgenius/dify)：参考把多步骤工作流与执行状态呈现给用户的方向。

这里只参考交互组织，自行实现页面和本地接口，没有复制这些项目的源码、品牌资源或完整架构。
