# 功能与范围

## 已实现

- 编码、审查与修复角色通过共享状态协作，实际验收独立于模型判断。
- 网页填写兼容接口的地址、模型和 API Key；密钥仅用于当前页面会话。
- 自然语言需求可先生成接口和验收草稿，用户确认后固定。
- 可视化添加角色、配置输入与提示词、拖动节点、手动连线及保存流程。
- 运行前检查流程结构和数据依赖，修复循环受次数与总步数上限约束。
- 可选独立验证者逐条核实候选问题，保留确认、驳回和待确认结论。
- 运行图、各轮节点输出、源码版本、验收结果、日志和报告可追溯。
- 支持历史任务、结果下载、流程导入导出和源码打包。

## 当前边界

任务范围是单文件同步 Python 函数，输入与预期结果使用 JSON 数据。自定义角色输出分析与建议，不能修改固定验收或调度规则。暂不支持并行、任意循环、多文件补丁或从快照自动续跑。

验收使用带超时的本机子进程，不是安全沙箱。通过有限验收与审查不等于证明所有输入正确。

离线演示使用固定模型结果，自定义提示词不会在离线模式执行。HTTP 模拟与自动化测试证明接口和调度行为，真实模型效果需要使用有效连接单独评估。
